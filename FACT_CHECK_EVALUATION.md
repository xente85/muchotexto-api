# Evaluación de análisis de evidencias

El resultado actual es una evaluación preliminar automática de afirmaciones, no una verificación periodística certificada. No usar tasas de acierto sin un conjunto de casos revisado por personas.

## Conjunto de evaluación

Reunir al menos 50 artículos con permiso para analizarlos, en español e inglés, de distintas fechas y temas. Incluir afirmaciones verdaderas, falsas, fuera de contexto, desactualizadas, mixtas y no verificables. Conservar URL, fecha de publicación, afirmación exacta, evidencia primaria y conclusión justificada por dos revisores. Separar al menos 20 casos para una prueba final que no se use al ajustar el sistema.

## Revisión de cada salida

Registrar por afirmación:

- Si la afirmación extraída representa fielmente el artículo.
- Si cada cita existe en la página enlazada y respalda la relación indicada. La coincidencia textual automática no demuestra que la interpretación sea correcta.
- Si las fuentes son realmente independientes; dos dominios pueden copiar la misma nota.
- Si fechas, unidades y contexto coinciden.
- Si la etiqueta coincide con la conclusión de los revisores.
- Si el sistema reconoció correctamente la falta de evidencia.

## Indicadores para decidir la publicación

Medir por separado la cobertura de afirmaciones, errores de extracción, citas incorrectas, conclusiones falsas presentadas como respaldadas, conclusiones verdaderas presentadas como contradichas y abstenciones. Revisar manualmente todos los errores graves. Comparar con el flujo anterior sobre los mismos artículos y registrar tiempo y coste por análisis.

La decisión comercial requiere primero fijar umbrales de error aceptables para el público previsto. Hasta medirlos, mantener la etiqueta «Análisis de evidencias» y el aviso de evaluación preliminar.
